Tips
  • Export your Front Desk AI calls as CSV first
  • Column names are matched case-insensitively
  • Phone numbers are normalized (dashes, spaces, parens removed) for matching
  • New customers are auto-created from call imports if not found
  • You can re-import the same file - duplicates won't be created for customers (calls will be added each time)
