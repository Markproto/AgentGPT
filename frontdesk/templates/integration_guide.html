My AI Front Desk Integration

Connect your My AI Front Desk (myaifrontdesk.com) account to automatically receive call data, transcripts, and caller information in this CRM.

Step 1: Configure the Post-Call Webhook
  1. Log into your My AI Front Desk admin dashboard
  2. Go to Settings → Integrations (or Webhooks)
  3. Add a new Post-Call Webhook with this URL:
    https://agent.opentruthai.com/frontdesk/calls/webhook/
  4. Set the method to POST
  5. Set content type to application/json
  6. Save and test the webhook
Note: This webhook URL is protected by basic auth (admin/opentruth). If My AI Front Desk doesn't support basic auth in webhook URLs, use this format instead:
https://admin:opentruth@agent.opentruthai.com/frontdesk/calls/webhook/
Step 2: What Data Gets Captured

After each call, My AI Front Desk sends a JSON payload. The CRM automatically extracts:

FieldSource Keys (auto-detected)
Phone Numberphone_number, caller_id, from
Call Directiondirection (defaults to INBOUND)
Durationduration, call_duration
Transcripttranscript, summary
Category/Intentcategory, intent
External IDid, call_id, callSid
Step 3: Automatic Customer Matching

When a call comes in, the CRM automatically:

  • Strips formatting from the phone number (dashes, spaces, parentheses)
  • Searches for an existing customer with a matching phone number
  • If found: links the call to that customer and creates an interaction record
  • If not found: creates the call log entry as "Unmatched" (you can manually link it later)
Step 4: Import Existing Call History
  1. In My AI Front Desk, export your call history as CSV
  2. Go to Import/Export in this CRM
  3. Select "Call Log" as the import type
  4. Upload the CSV file
  5. The system auto-detects column names and imports all records
  6. New customers are automatically created for unmatched phone numbers
Twilio SMS Integration

Send and receive text messages through Twilio. Customer replies are captured and shown in the conversation history.

Step 1: Get Twilio Credentials
  1. Sign up at twilio.com
  2. Get a phone number with SMS capability
  3. Find your Account SID and Auth Token on the Twilio Console dashboard
Step 2: Add Credentials to CRM

SSH into your server and edit the environment file:

nano /opt/frontdesk/.env

Add your Twilio credentials:

TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_PHONE=+1234567890

Then restart the CRM:

cd /opt/frontdesk && docker compose restart
Step 3: Configure Inbound SMS Webhook

To receive customer reply texts:

  1. Go to your Twilio Console → Phone Numbers → Manage → Active Numbers
  2. Click your phone number
  3. Under Messaging → "A Message Comes In", set:
    • Webhook URL: https://agent.opentruthai.com/frontdesk/sms/webhook/
    • HTTP Method: POST
  4. Save
Important: The SMS webhook endpoint bypasses basic auth (it's csrf_exempt for Twilio access). The URL must be accessible without authentication.
Step 4: How It Works
  • Sending: Go to Texting, select recipients, type message, click Send
  • Receiving: When a customer replies, Twilio forwards the text to the webhook. The CRM matches the phone number to a customer and stores the message.
  • Conversation View: Click any customer → view their full text conversation history in a chat-style thread
  • Unknown Numbers: If an inbound text doesn't match any customer, a new customer is automatically created
SendGrid Email Integration

Send email messages to customers who don't have a phone number on file.

Setup
  1. Sign up at sendgrid.com
  2. Create an API key with Mail Send permissions
  3. Verify a sender email address
  4. Add to your environment file: 
    SENDGRID_API_KEY=SG.xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  5. Restart: cd /opt/frontdesk && docker compose restart

When you send a message from the Texting page, customers with a phone get SMS (via Twilio). Customers with only an email get the message via SendGrid.

AI Integration (Claude / Grok)

AI capabilities are available for analyzing call transcripts and generating customer insights.

Setup

Add one or both API keys to your environment file:

# Anthropic Claude
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxxx

# Grok (xAI)
GROK_API_KEY=xai-xxxxxxxxxxxxxxxxxxxxxxxxx

Then restart: cd /opt/frontdesk && docker compose restart
