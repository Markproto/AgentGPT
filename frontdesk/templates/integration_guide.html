Twilio SMS Setup

The texting system uses Twilio to send and receive SMS messages. This section covers setup for the administrator and daily usage for staff.

1 Twilio Account & Credentials Admin Only
  1. Create a Twilio account at twilio.com
  2. Buy a phone number with SMS capability (Phone Numbers → Buy a Number)
  3. Find your credentials on the Twilio Console dashboard:
CredentialStarts WithWhere to Find
Account SIDACDashboard — top of page
Auth Token(click "Show")Dashboard — next to Account SID
Phone Number+1Phone Numbers → Active Numbers
You only need the Account SID (starts with AC) and Auth Token. If you also generated API Keys (SK...) or a Messaging Service SID (VA...), those are not needed for this setup.
2 Server Configuration Admin Only

Add your Twilio credentials to the .env file on the server. Docker loads this automatically.

# SSH into your server, then edit the environment file:
nano /opt/frontdesk/.env

# Add these three lines (replace with your real values):
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_PHONE=+12065551234

After saving, restart the containers:

cd /opt/frontdesk
docker compose down && docker compose up -d
Never commit the .env file to git. It contains secrets.
3 Webhook Configuration (Receive Incoming Texts) Admin Only

For the system to receive incoming text messages, Twilio needs to know where to forward them.

  1. In Twilio Console: Phone Numbers → Manage → Active Numbers
  2. Click your phone number
  3. Scroll down to the Messaging section (NOT the Voice section)
  4. Under "A message comes in", set:
    Webhook URLhttps://agent.opentruthai.com/frontdesk/sms/webhook/
    MethodHTTP POST
  5. Click Save configuration
Common mistake: The webhook must be set under the Messaging section, NOT the "Voice & Fax" section. They look similar but are different sections on the same page. If you set it under Voice, incoming texts will not work.
When configured correctly: When someone texts your Twilio number, the message appears automatically in the Recent Messages panel and in the customer's conversation thread.
Sending Text Messages Daily Use
  1. Go to Texting in the sidebar
  2. Filter recipients using the Quick Filter dropdowns:
    • Action — Buying or Selling
    • Metal — Gold, Silver, Platinum, Palladium
    • Form — Bullion, Scrap, Other
  3. Select recipients — hold Ctrl (or Cmd on Mac) to pick multiple, or click "Select All Recipients"
  4. Choose a template (optional) from the Template dropdown, or type your own message
  5. Click Send Message
  6. A popup confirms how many sent, plus any errors (e.g., missing phone numbers)
Standard SMS is 160 characters per segment. The character counter below the message box tracks your length. Messages over 160 chars still send but count as multiple SMS segments on your Twilio bill.
Every sent message is recorded as an interaction on the customer's record, even if the Twilio API fails. You always have an audit trail.
Receiving Text Messages Automatic

Once the webhook is set up (Step 3), incoming texts are handled automatically:

  1. Customer texts your Twilio phone number
  2. Twilio forwards the message to Front Desk
  3. System matches the sender's phone number to an existing customer
  4. If no match found, a new customer record is created as "Unknown (+1XXXXXXXXXX)"
  5. The message is saved and appears in:
    • Recent Messages panel on the Texting page
    • The customer's Conversation thread
No auto-reply is sent. You decide when and how to respond from the Texting page or Conversation view.

Calendar

The calendar is the main daily workspace. It shows all appointments and notes for the day, week, or month. Access it from Calendar in the sidebar.

Creating Appointments

There are two ways to create an appointment:

Method 1: Click a time slot
  1. In Day or Week view, click (or click-and-drag) on a time slot
  2. The New Appointment form opens with the time pre-filled
  3. Fill in the fields (see below) and click Save Appointment
Method 2: Click on a date in Month view
  1. Click any date cell in the month view
  2. The form opens with that date selected
Appointment Fields:
FieldRequiredDescription
CustomerYesType a name. Existing customers appear in a dropdown. New names are automatically created as new customers.
PhoneNoCustomer phone number. Saved to the customer record.
Date & TimeYesStart time (auto-filled when you click a slot)
End TimeNoIf blank, defaults to 30 minutes after start
PurposeYesWhy they're coming in (e.g., "Buy 10oz Gold Bullion")
NotesNoAny extra info (e.g., "Repeat customer, prefers cash")
ActionNoBuying or Selling

Fast Entry (Keyboard Shortcuts)

For quick data entry when the phone is ringing, use the Tab key to fly through the form:

Customer Name Tab Phone Tab Purpose Tab Notes Enter Saved!
You can press Enter from any field to immediately save the appointment. This makes it fast to book while on the phone: click a time slot → type name → Tab → type phone → Tab → type purpose → Enter. Done.
Managing Appointments
Viewing details:

Click any appointment on the calendar to open the detail popup. It shows customer name, phone, purpose, category, status, notes, and time.

Editing:
  1. Click the appointment to open the detail popup
  2. Click the Edit button
  3. Change any fields (customer, phone, time, purpose, notes, categories)
  4. Click Save Changes
Drag & Drop:

In Day or Week view, drag an appointment to a new time slot to reschedule it. The change saves automatically.

Deleting:

Click the appointment → click Delete → confirm. This is permanent.

Day Notes

Notes are lightweight reminders that appear on the calendar alongside appointments. They show as dashed blue boxes taking up half the width so appointments can sit next to them.

Adding a note:
  1. Click the + Note button in the calendar toolbar
  2. Set the date and (optional) time
  3. Type the note content
  4. Click Save Note
Managing notes:
  • View: Click a note on the calendar to read it
  • Edit: Click the note → click Edit → change content → Save
  • Move: Drag and drop to a new time/date
  • Delete: Click the note → click Delete
Notes without a time appear as all-day items at the top. Notes with a time appear in the time grid at 15-minute size, taking half width so appointments still fit beside them.
Customer Categories

Every customer (and appointment) can be tagged with three optional category fields:

CategoryOptionsPurpose
ActionBuying, SellingWhat the customer is doing

These categories are used in:

Customers

Customer Spreadsheet

Go to Customers in the sidebar. The spreadsheet lets you view and edit all customer data in a familiar Excel-like grid.

Columns:
  • Name — Customer's full name
  • Phone — Phone number (used for texting and matching inbound calls/texts)
  • Email — Email address (fallback for SendGrid)
  • Action — Buying / Selling (dropdown)

Import & Export

Go to Import/Export in the sidebar.

Importing customers from CSV:
  1. Prepare a CSV with columns: Name, Phone, Email, Action, Metal, Form
  2. Accepted Action values: BUYING, SELLING
  3. Accepted Metal values: GOLD, SILVER, PLATINUM, PALLADIUM
  4. Accepted Form values: BULLION, SCRAP, OTHER
  5. Upload the CSV and select "Customer" as the import type
Exporting:
  • Export Texts as CSV — all text message history
  • Export Calls as CSV — all call log records

Call Log & AI Front Desk Integration

The call log captures calls from My AI Front Desk (myaifrontdesk.com) via a webhook.

Setup (Admin):
  1. In your My AI Front Desk dashboard, go to Settings → Integrations
  2. Add a Post-Call Webhook: https://agent.opentruthai.com/frontdesk/calls/webhook/
  3. Method: POST, Content-Type: application/json
What gets captured:
  • Caller phone number, direction (inbound/outbound), duration, transcript
  • System auto-matches phone numbers to existing customers
  • Unmatched calls show as "Unmatched" — you can link them manually
Importing existing history:

Export call history from My AI Front Desk as CSV → upload via Import/Export → select "Call Log" type.

Troubleshooting

  • Check the phone number format — must include country code (e.g., +12065551234)
  • Trial account? On Twilio trial, you can only send to verified numbers. Go to Twilio Console → Verified Caller IDs and add the number.
  • Check your Twilio balance — prepaid accounts can run out
  • Check logs: docker logs frontdesk-web --tail 100

  • Most common: Webhook is set under Voice Configuration instead of Messaging. Check Twilio phone number settings → scroll to Messaging section.
  • URL must be exactly: https://agent.opentruthai.com/frontdesk/sms/webhook/ (trailing slash required)
  • Method must be HTTP POST
  • Check Twilio Error Logs: Monitor → Logs → Errors
  • Verify HTTPS is working on the server

The customer doesn't have a phone number saved. Add it via:

  • Customers spreadsheet — find the customer and type their phone number
  • Calendar — click the appointment → Edit → add the phone number

  • Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
  • Clear browser cache
  • Check if the server is running: docker compose ps
  • Check logs: docker logs frontdesk-web --tail 50

  • The .env file must be at /opt/frontdesk/.env (same folder as docker-compose.yml)
  • No quotes around values: TWILIO_PHONE=+12065551234 not TWILIO_PHONE="+12065551234"
  • Must do a full restart: docker compose down && docker compose up -d
  • Verify: docker exec frontdesk-web env | grep TWILIO

  • Can only send to verified phone numbers
  • Outgoing messages prefixed with "Sent from your Twilio trial account"
  • Incoming texts work normally
  • Upgrade to paid account to remove all restrictions

Tark1 Voice AI Integration

1 Overview

Tark1 is the AI voice receptionist running on 192.168.1.200:3001 (public: voice.huttonetwork.com). When a customer calls J. Austin at (541) 631-3838, Tark1 answers, detects what they want, and uses the Toggle Board in Frontdesk to decide whether to auto-schedule or request a callback.

Flow: Customer calls → Tark1 answers → Detects product category → Checks Toggle Board → Auto-schedules OR tells caller to wait for callback.
2 Toggle Board

Go to Toggle Board in the sidebar. You'll see five product categories:

CategoryToggle ONToggle OFF
Scrap GoldAuto-schedule appointmentCallback required
Scrap SilverAuto-schedule appointmentCallback required
Gold EaglesAuto-schedule appointmentCallback required
1 oz Silver RoundsAuto-schedule appointmentCallback required
1 oz Silver EaglesAuto-schedule appointmentCallback required
Tip: Items not on the toggle board (e.g., platinum bars, palladium) will always require a callback. The voice AI will say "Let me have someone call you back about that."
3 API Endpoints (for Tark1 developers)

Check toggle status:

GET /api/toggles/

// Response:
{
  "toggles": {
    "SCRAP_GOLD": { "label": "Scrap Gold", "auto_schedule": true },
    "SCRAP_SILVER": { "label": "Scrap Silver", "auto_schedule": false },
    ...
  }
}

Auto-schedule appointment:

POST /api/voice-schedule/

{
  "caller_name": "John Smith",
  "caller_phone": "+15415551234",
  "category": "SCRAP_GOLD",
  "preferred_date": "2026-03-04", // optional
  "preferred_time": "14:00", // optional
  "notes": "Has about 3 oz scrap gold", // optional
  "location": "Ashland" // optional, defaults to J. Austin Office
}

Tark1 decision logic (pseudocode for server.js):

// After detecting customer intent...
const res = await fetch('http://apollo9:8001/api/toggles/');
const { toggles } = await res.json();

if (toggles[category] && toggles[category].auto_schedule) {
  // Ask for name, phone, preferred time
  // POST to /api/voice-schedule/
  say("Great, I've scheduled you for tomorrow at 10 AM.");
} else if (toggles[category]) {
  say("We'll have someone call you back shortly about that.");
} else {
  say("Let me have someone call you back about that.");
}
Important: The POST /api/voice-schedule/ endpoint will return a 403 if the toggle is OFF, preventing accidental scheduling. Tark1 should always check toggles first.
